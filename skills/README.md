# Skills

本目录存放可由 Coding Agent 触发的专项能力。每个 Skill 至少包含 `SKILL.md`，并清晰说明适用场景、输入、执行步骤、输出与限制。

| Skill | 用途 | 适用场景 |
| --- | --- | --- |
| [rg-code-review](rg-code-review) | 团队级增量代码审查 | Java、PHP、Go、Python 的提交前检查或 PR 审查 |

新增 Skill 前，请先检查它是否应归为通用规则或任务工作流，避免把所有文档都包装成 Skill。具体准入标准见 [架构说明](../docs/architecture.md)。
